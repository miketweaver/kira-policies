# kira-policies

Policies for Kira, an AI assistant that invited people chat with by text
message (SMS and RCS), messaging apps, and web or app chat.

- [Privacy Policy](PRIVACY.md)
- [Terms of Service](TERMS.md)

Changes to either document are made as commits to this repository, so its
history is the record of every version. General questions: open an
[issue](https://github.com/miketweaver/kira-policies/issues). Issues are
public; for anything about your own information, message Kira or contact
the person who invited you.
